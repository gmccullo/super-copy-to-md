Copy any selected webpage content as clean, ready-to-paste Markdown with a single right-click.

HOW IT WORKS

Right-click anywhere on a page to get a context-sensitive set of copy actions under "Super copy to markdown". The result is written to your clipboard — ready to paste into Obsidian, Bear, Notion, a text editor, or anywhere you write.

COPY ACTIONS

📝 Copy as markdown — converts selected HTML to clean Markdown.

🔖 Copy as quote — same as above, wrapped in a Markdown blockquote with a "~ [Page Title](url)" attribution line.

🔗 Copy as link — uses selected text as the caption of a Markdown link to the current page.

🌐 Copy page link — copies the page title and URL as a Markdown link, no selection needed.

🔀 Copy link as markdown — right-click any hyperlink to copy it as a Markdown inline link.

🖼️ Copy image as markdown — right-click any image to copy it as a Markdown image embed.

FEATURES

📊 GFM tables — HTML tables convert to aligned GitHub Flavored Markdown tables. Select only part of a table and it automatically includes the header row plus the rows you touched.

🔗 Clean URLs — fully qualified, human-readable URLs in angle brackets. No relative paths, no percent-encoding.

🔀 Inline or reference links — choose between inline "[text](<url>)" or reference-style "[text][1]" links with definitions appended.

✨ Linter-clean output — 1 space after list markers, no trailing spaces, smart _ vs * for emphasis.

OPTIONS

Right-click anywhere and choose Super copy to markdown → Options to configure the link style.
